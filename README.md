# 🚀 TFDrive All-In-One Toolkit (Google Colab)

Aplikasi pengunduh serbaguna langsung ke **Google Drive** pribadi Anda via Google Colab tanpa kuota internet lokal dan tanpa memakan kapasitas hard disk PC.

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/zufarrizal/TFDrive/blob/master/TFDrive_Colab.ipynb)

---

## ⚡ Cara Cepat Buka di Colab:
Cukup klik lencana **[Open in Colab](https://colab.research.google.com/github/zufarrizal/TFDrive/blob/master/TFDrive_Colab.ipynb)** di atas, lalu Anda langsung diarahkan ke notebook siap pakai.

---

## ✨ Fitur Utama:

1. **📥 Batch & Multi-Link Downloader** (Single wget / Multi aria2c 16x).
2. **🧲 Torrent & Magnet Downloader** (Direct aria2c to Drive).
3. **🗜️ Auto-Extract Arsip** (RAR, ZIP, 7z, Multipart .part1.rar).
4. **📹 Video & Audio Downloader** (YouTube, TikTok, Twitter/X, IG kualitas 4K/MP3).
5. **🔌 SSH Terminal Connect (tmate)**: Memungkinkan kendali langsung dari terminal PC atau asisten AI.
